# ManualMap-Injector
Инжектор динамических библиотек (DLL) для операционных систем Windows.

Этот Проект представляет собой Proof of Concept (PoC) для исследования техник Manual Mapping, обхода inline-хуков и анализа того, как подобные механизмы детектируются современными EDR/AV-решениями. Проект делает упор на использование прямых системных вызовов и тщательную очистку следов присутствия в памяти.

Основные возможности

* Manual Mapping: Полностью ручная загрузка PE-образа в память целевого процесса без использования стандартного API Windows.

* Hell's Gate: Использование техники Hell's Gate для динамического поиска номеров системных вызовов (SSN) напрямую из ntdll.dll. Это позволяет обходить user-mode хуки, установленные защитными системами.

* Собственный Shellcode Loader: Встроенный лоадер самостоятельно обрабатывает релокации и таблицу импортов. Также он поддерживает SEH-таблицы и выполняет TLS-колбэки перед вызовом DllMain.

* Erase PE Artifacts: Затирание PE-заголовков и имен секций после успешного инжекта для защиты от сигнатурного сканирования памяти.

* Apply Section Protections: Корректное восстановление прав доступа к секциям памяти после инициализации загруженного образа.

* Динамические Syscall Stubs: Генерация стабов для вызовов NtOpenProcess, NtAllocateVirtualMemory, NtWriteVirtualMemory, NtCreateThreadEx, NtProtectVirtualMemory, NtFreeVirtualMemory и NtQuerySystemInformation.

* Скрытный поиск PID: Поиск целевого процесса реализуется через системный вызов NtQuerySystemInformation.

Требования

* Компилятор с поддержкой C++17 или выше.

* Целевая архитектура: x64 (x86 не поддерживается, так как используется специфика 64-битных регистров и релокаций).

Инструкция

1. Скомпилируйте проект в режиме Release (x64).

2. Поместите вашу библиотеку в одну папку с исполняемым файлом инжектора. По умолчанию инжектор ожидает файл с именем payload.dll.

3. Запустите инжектор от имени Администратора.

4. Запустите целевой процесс. Программа автоматически найдет его по имени, произведет инжект и очистит за собой следы.
